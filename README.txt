KEERTHI S — PROFESSIONAL PORTFOLIO

FILES
- index.html: Home / portfolio
- resume.html: Resume with print-to-PDF support
- biodata.html: Public-facing bio-data
- style.css: Shared responsive design system
- script.js: Mobile navigation, theme toggle and reveal effects

HOW TO RUN
1. Extract this ZIP.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html with the Live Server extension, or double-click index.html.
4. Internet is needed for Google Fonts. The site otherwise uses plain HTML, CSS and JavaScript.

BEFORE PUBLISHING
- Verify every education year, institution name, percentage and project description.
- Replace the sample email address with a professional email you actively use.
- Add GitHub and LinkedIn profile links after confirming their URLs.
- Add project screenshots and repository links when available.
- Public pages intentionally omit your full home address, date of birth, gender and personal phone number. Keep a separate private bio-data document if an application specifically requests those details.
- The portfolio does not claim professional employment or project features that were not in the supplied source.

HOSTING
You can publish this static website using GitHub Pages, Netlify or Vercel.
